# Character Description: Pip

**Age Group:** Young child (similar to Sam/Rat).
**Appearance:**
*   **Species:** Pig.
*   **Color:** Soft pink skin.
*   **Facial Features:** Large, expressive anime-style eyes, cute snout, friendly smile.
*   **Style:** Modern Storybook Anime style. Natural animal, no anthropomorphism (no clothes, walks on four legs).
*   **Clothing:** None (Natural animal).
**Personality:** Cheerful, playful, and maybe a bit messy (likes mud?).
